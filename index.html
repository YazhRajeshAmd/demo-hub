FSI Stock Intelligence

Technical indicators + LLM commentary for equity research

Pulls live pricing from Yahoo Finance, computes SMA, RSI, and momentum, then hands the result to a Phi-4 model served through ROCm vLLM for plain-English analysis — all inside a Gradio UI.

Python Gradio LangChain vLLM · ROCm yfinance
How to run 
# clone & install
git clone https://github.com/YazhRajeshAmd/fsi-stock-analysis
cd fsi-stock-analysis
pip install -r requirements.txt

# run (needs a reachable vLLM endpoint)
export VLLM_API_BASE=http://<host>:8000/v1
python FSI_StockAnalysis_vLLM.py
# open http://localhost:7860

Requires a running Phi-4 vLLM endpoint. Point VLLM_API_BASE at any ROCm vLLM server running on an Instinct GPU.

LightGBM ROCm · Credit Risk

GPU-accelerated gradient boosting for loan default prediction

Trains a LightGBM binary classifier on the Home Credit default-risk dataset, comparing a ROCm-built GPU histogram backend against CPU training side by side — with AUC, accuracy, and runtime charts rendered in an AMD-branded Gradio UI.

Python Gradio LightGBM · ROCm scikit-learn
How to run 
# clone
git clone https://github.com/YazhRajeshAmd/lightgbm_rocm
cd lightgbm_rocm

# build LightGBM with ROCm GPU support, then:
cmake -DUSE_GPU=1 -DUSE_ROCM=1 -B build -S . -D CMAKE_PREFIX_PATH=/opt/rocm
make -j && ./build-python.sh install --gpu

python lightgbm_gpu_homecredit.py   # GPU
python lightgbm_cpu_homecredit.py   # CPU comparison

Needs LightGBM compiled with USE_ROCM=1 against an Instinct GPU, plus the Kaggle Home Credit dataset (application_train.csv).

SE(3) Transformer Drug Discovery

Equivariant transformer for molecular property prediction

Predicts molecular properties — HOMO, LUMO, dipole moment, and more — from the QM9 dataset using an SE(3)-equivariant graph transformer, with interactive 3D molecule rendering via RDKit and py3Dmol in a Streamlit UI.

Python Streamlit PyTorch · DGL RDKit / py3Dmol QM9
How to run 
# clone & install
git clone https://github.com/YazhRajeshAmd/rocm_ls_se3
cd rocm_ls_se3
python3 -m venv venv && source venv/bin/activate
pip install torch==2.1.0 torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm5.6
pip install numpy pandas matplotlib plotly streamlit rdkit py3dmol dgl

# run
streamlit run ui_drug_discovery.py
# open http://localhost:8501

DGL graph ops run fastest with a ROCm-enabled Instinct GPU; falls back to CPU if none is present.

ROCm RAG Assistant

Multi-LLM RAG assistant for ROCm install & troubleshooting

Answers ROCm installation and configuration questions by retrieving from a ChromaDB knowledge base built from scraped ROCm docs, then load-balancing the query across four parallel Ollama (Llama 3.1 8B) instances and picking the strongest response — all behind a Gradio chat UI.

Python Gradio LangChain Ollama · Llama 3.1 8B ChromaDB
How to run 
# clone & install
git clone https://github.com/YazhRajeshAmd/rocm-rag-assistant
cd rocm-rag-assistant
pip install -r requirements.txt

# start the 4 Ollama instances, then run the assistant
cd gpu1 && ./start_ollama.sh
python rocm_assistant_enhanced.py
# open http://localhost:7862

Needs 4 Ollama instances serving llama3.1:8b on an Instinct GPU; degrades gracefully if some instances aren't up.
