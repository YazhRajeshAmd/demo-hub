Equity research & risk modeling on ROCm

FSI Stock Intelligence

Technical indicators + LLM commentary for equity research

Pulls live pricing from Yahoo Finance, computes SMA, RSI, and momentum, then hands the result to a Phi-4 model served through ROCm vLLM for plain-English analysis — all inside a Gradio UI.

Python Gradio LangChain vLLM · ROCm yfinance
How to run 
# clone & install
git clone https://github.com/YazhRajeshAmd/fsi-stock-analysis
cd fsi-stock-analysis
pip install -r requirements.txt

# run (needs a reachable vLLM endpoint)
export VLLM_API_BASE=http://<host>:8000/v1
python FSI_StockAnalysis_vLLM.py
# open http://localhost:7860

Requires a running Phi-4 vLLM endpoint. Point VLLM_API_BASE at any ROCm vLLM server running on an Instinct GPU.

ROCm XGBoost · Stock & Fraud Models

GPU-trained XGBoost for direction prediction and backtesting

Engineers 15+ technical and market-wide features, trains an XGBoost classifier on an AMD Instinct GPU via the ROCm HIP backend, then backtests the resulting signal with equity curves, ROC/AUC, and feature-importance charts — plus a credit-card fraud-detection variant on the same pipeline.

Python Gradio XGBoost · ROCm HIP scikit-learn yfinance
How to run 
# clone & install
git clone https://github.com/YazhRajeshAmd/fsi_rocm_xgboost
cd fsi_rocm_xgboost
pip install yfinance pandas numpy scikit-learn matplotlib gradio pillow xgboost

# install ROCm-enabled XGBoost for your Instinct GPU, then:
python rocm_finance_xgboost.py
# open http://localhost:7860

Trains with device="gpu" on the ROCm HIP backend — works on any ROCm-supported Instinct GPU.

Medical imaging AI on ROCm

MRI Analysis Tool

DICOM/NIfTI analysis with an LLM-drafted radiology report

Loads MRI studies in DICOM or NIfTI format, runs denoising, contrast enhancement, and k-means tissue segmentation, then drafts a structured, report-style summary using Llama 3.1 70B served locally through Ollama.

Python Gradio PyTorch Ollama · Llama 3.1 70B PyDICOM / NiBabel
How to run 
# clone & install
git clone https://github.com/YazhRajeshAmd/mri-analysis-tool
cd mri-analysis-tool
pip install -r requirements.txt

# point at an Ollama server (local or remote)
export OLLAMA_HOST=http://<host>:11434
python mri_main.py
# open the Gradio URL printed in the terminal

Educational / research use only — not a diagnostic tool. Point OLLAMA_HOST at any Instinct-hosted Ollama server running Llama 3.1 70B.

MONAI Pathology Analysis

Whole-slide tumor detection with DenseNet121 + hipCIM

Reads whole-slide pathology images (.svs, .ndpi, .scn) via hipCIM — AMD's ROCm port of cuCIM — and classifies tumor regions with a MONAI DenseNet121 model, served through a FastAPI backend behind an AMD-branded web UI.

Python FastAPI MONAI · DenseNet121 hipCIM · ROCm
How to run 
# clone & install
git clone https://github.com/YazhRajeshAmd/rocm_monai_pathology
cd rocm_monai_pathology
./setup.sh

# serve
uvicorn chatbot_monai_medical:app --host 0.0.0.0 --port 8000 --reload
# open http://localhost:8000

hipCIM requires a ROCm-enabled Instinct GPU (MI200/MI300 series or newer).
